## Which Entry Should I Use?

Use the public **Work Order Request** when you are reporting a problem and are not creating a native internal Work Order in Work Management.

Managers may instead open [Work Orders](https://my.sheboyganlights.org/workorder/) and use **Create Work Order** when the work is already known to be a legitimate internal Work Order.

The public request creates **Work Order Intake** for Manager review. It does not immediately create an active Work Order.

> **Testing exception:** if a Test Session already created a repair Work Order, do not submit another request for the same repair.

## Submit the Public Request

1. Open the MSB Internal homepage.
2. Choose the Work Order request action.
3. Complete the Google Form.
4. Choose **Park** or **Workshop** as appropriate.
5. Describe the problem and location clearly.
6. Submit once.

The submitted Priority is a reporter estimate. The Manager may change urgency during triage.

## Priority Reference

| Priority | Meaning |
|---|---|
| **1** | Immediate / Critical |
| **2** | High |
| **3** | Normal |
| **4** | Low |
| **5** | Planning |

## What Happens Next

The request appears in Work Management under **Public Intake**. A Manager may:

- ask the reporter for more information;
- promote the request into an active Work Order and assign it;
- retain it for further review; or
- close/reject/no-action it with a reason.

The current notification system can send reporter clarification and final-outcome messages when the reporter has an eligible address/account. Managers can see delivery state and must follow up when delivery is missing or failed.

## Expected Result

One Intake record preserves the original reporter and request evidence. If approved, a linked native Work Order is created through Manager triage.
