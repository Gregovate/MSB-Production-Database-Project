## Purpose

Use this procedure when you need to report a problem or request work that should be reviewed by a manager.

Most new work begins as a Work Order Request submitted from the **Work Order** button on `my.sheboyganlights.org`.

Submitting the request creates an **Intake Record**. It does not create an active Work Order until a manager reviews and promotes it.

## Procedure

1. Open `my.sheboyganlights.org`.
2. Select the **Work Order** button.
3. Complete the Work Order Request form with enough information for a manager to understand the issue.
4. Submit the request.

Useful requests clearly describe what is wrong or what work is needed. Examples include:

- display not powering on;
- broken frame;
- loose wiring;
- facility problem;
- safety concern;
- missing parts; or
- another issue that needs organized follow-up.

## Expected Result

The request is stored in the Work Order Intake system for manager review.

A manager decides whether the request should be deleted, held for later review, or promoted into an active Work Order.

## Important

Do not submit a separate Work Order Request for a repair that is already being created automatically by the display-testing workflow.
