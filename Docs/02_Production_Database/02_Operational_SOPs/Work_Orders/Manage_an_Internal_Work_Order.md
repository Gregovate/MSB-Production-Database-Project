# Manage an Internal Work Order

[Work Orders Home](README.md)

Status: CURRENT Phase 1; Phase 2 additions pending. Owner: Production Database Manager. Reviewed 2026-10-20.

1. Open [Work Orders](https://my.sheboyganlights.org/workorder/) as a Manager and choose Create Work Order.
2. Describe the actual job, choose Task Type and Urgency, and select one Stage or Work Area. No fake Intake is needed.
3. Planning priority 5 requires Target Year. Use the planning toggle to find planning work hidden from routine views.
4. Select volunteers or deliberately retain unassigned work for Manager follow-up. Save once and verify the result.

Use the existing order's Manager correction action with a substantive reason to change details, or Assign / Reassign to update volunteers. Cancellation requires a reason and means no further work on that order; it is not completion. Completed records are not ordinary editable work. Testing-linked correction/cancellation needs its separate governed review.

Review unassigned work and the Open Work Order Aging Report. Age is elapsed time since creation, not a promised deadline.

Pending Phase 2: required Due by on Create/Promote, Manager date edits, missing-date flags and overdue indicators. Dates will not be invented for historical work. Due today is not overdue. Phase 1 native application saves do not send the new emails; contact recipients directly until delivery cutover is verified.

See the [notification procedure](Phase_1_and_Phase_2_Notification_Procedure.md).
