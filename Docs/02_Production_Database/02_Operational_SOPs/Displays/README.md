# Display Operational SOPs

These procedures are for operators maintaining Production Database information about displays after LOR-derived records have entered PostgreSQL.

## What Do You Need To Do?

| I want to... | Go to |
|---|---|
| Complete metadata for a newly imported display | [Complete Display Metadata After LOR Import](Complete_Display_Metadata_After_LOR_Import.md) |

## Scope

Display names, LOR identities, stage relationships, and show topology originate from the LOR/LOR2DB process. These operator procedures cover Production Database enrichment and operational information that is maintained after ingest.

For engineering ownership and database behavior, use the [Production Database System Architecture](../../01_System_Architecture/README.md).
