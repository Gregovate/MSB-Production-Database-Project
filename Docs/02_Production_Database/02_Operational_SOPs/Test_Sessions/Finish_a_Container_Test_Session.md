## Purpose

Use this procedure when all required display testing for a container has been completed and the container is ready to return to storage.

## Before You Start

Confirm that:

- every required display has been evaluated;
- no repair items remain open;
- no deferred items remain;
- no wrong-container items remain; and
- all required displays are physically accounted for.

## Procedure

1. Review all Display Checks for the container.
2. Resolve any unfinished repair, deferred, or wrong-container items before continuing.
3. Change the container test status to **Done**.
4. Save the test-session record.
5. Remove the yellow tag when no unfinished work remains.
6. Mark the container ready for setup using the current green-tag practice.
7. Return the container to its Home Location.

## Expected Result

- The container test session is **Done**.
- No unfinished testing items remain.
- The container is physically returned to the correct Home Location.
- The container is identified as ready for setup.

## If Something Is Wrong

If any display still requires repair, is deferred, is assigned to the wrong container, or is not physically accounted for, leave the container **In Progress** and resolve that item first.
