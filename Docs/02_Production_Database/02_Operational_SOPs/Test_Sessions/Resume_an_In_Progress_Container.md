## Purpose

Use this procedure when testing was started earlier and needs to continue later.

## Procedure

1. Open **Containers In Progress**.
2. Find the container you are continuing.
3. Open the test-session record.
4. Review the existing Display Checks and notes before doing more work.
5. Continue testing the unfinished displays.
6. Save each display test record as work is completed.

## Expected Result

Testing continues from the existing test-session records without creating a new session or losing previous results.
