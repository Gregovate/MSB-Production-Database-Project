# Test Session Operational SOPs

Use these procedures for annual container/display testing and testing-related manager corrections.

## What Do You Need To Do?

| I want to... | Go to |
|---|---|
| Test a container and the displays assigned to it | [Container Testing & Repair SOP](A_Container_Testing_and_Repair_SOP.md) |
| Correct test-session/display assignment problems that involve existing work orders | [Manager Correction — Wrong Display Container With Existing Work Orders](Troubleshooting.md) |
| Prepare a new annual testing season | [Manager Annual Test Season Setup](Manager_Annual_Test_Season_Setup.md) |

## Current Documentation Status

The existing Container Testing & Repair SOP predates the current Operational SOP Standard and is being audited against the current Production Database and Directus behavior before it is replaced or renamed.

The manager correction procedure also predates the current standard and contains direct SQL. It is manager/DBA-only material, not a general volunteer troubleshooting guide.

The annual test-season setup procedure is currently a draft because the 2026 season was launched manually and a repeatable manager procedure has not yet been fully documented.
