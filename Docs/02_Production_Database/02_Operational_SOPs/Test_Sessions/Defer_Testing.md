## Purpose

Use this procedure when testing cannot be completed now because different tools, equipment, time, or personnel are needed.

## Procedure

1. Open the display test record.
2. Select the current test result used for deferred work.
3. Add notes explaining what is still needed.
4. Save the display test record.
5. Keep the container test session **In Progress**.
6. Place or keep the yellow tag on the container so unfinished work is visible.
7. Return the container to its Home Location or leave it in the Work Location, as directed for the current work period.

## Expected Result

The unfinished item is documented, the container remains **In Progress**, and another volunteer can understand what is needed before testing resumes.
