## Purpose

Use this reference when you need help choosing the correct result for a display test.

## Test Results

### OK

The display works as designed and no further action is needed.

### OK-REPAIRED

Use when a problem was corrected during testing and the display is now working correctly. Add a note describing what was corrected.

### REPAIR W/O

Use when the display needs additional repair work and a Work Order must be created. Add notes describing the problem.

### DEFERRED

Use when testing is intentionally paused because additional tools, equipment, time, or personnel are needed. Deferred is not a failed test.

### WRONG CONTAINER

Use when the display test record is associated with a container where the display does not belong. Correct the display's actual container assignment before refreshing the test session.
