## Purpose

Use this procedure when a display needs repair beyond what can be completed immediately during testing.

## Before You Start

- The container test session is **In Progress**.
- The display has been physically inspected and the repair need is understood well enough to describe it.

## Procedure

1. Open the display test record.
2. Mark the display as physically present when it is present on the container.
3. Select the current testing result used for **Repair Work Order**.
4. Enter notes describing what is wrong. Repair notes are required.
5. Save the display test record.
6. Confirm that the repair Work Order was created.
7. Place a yellow tag on the display and note what is wrong.
8. Remove the display from the container and move it to the repair area.
9. Place or keep a yellow tag on the container showing that a display has been removed for repair.
10. Leave the container test session **In Progress** until the repair is completed and the display is returned.

## Expected Result

- The repair need is recorded in the display test history.
- A repair Work Order exists for the display.
- The display is clearly tagged and moved to the repair area.
- The container remains **In Progress** while repair work is outstanding.

## If Something Is Wrong

If the repair Work Order does not appear after saving, do not keep resaving the test record. Ask a manager for help before continuing.

If the display is actually on the wrong container rather than needing repair, do not create a repair Work Order for that mismatch. Use [Handle a Wrong or Missing Display](Handle_a_Wrong_or_Missing_Display.md).
