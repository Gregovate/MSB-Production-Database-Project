- annotated examples used by Folder Alignment operator procedures;
- diagrams explaining Folder Alignment workflow; and
- report screenshots used by Folder Alignment engineering documentation.

The current Folder Alignment engineering design and converted operator procedures were checked during the proof conversion and do not currently embed Markdown images, so no existing image asset needed to move into this folder.
