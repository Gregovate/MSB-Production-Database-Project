# Introduction

This guide provides a visual reference for the tools used throughout the MSB Documentation Project.

As you work through the training, additional screenshots will be added to this document to illustrate the Visual Studio Code and GitHub user interface.

Until those screenshots are available, the official Microsoft and GitHub documentation is provided for each topic.

---

# 6 — Publish Branch

After committing your changes, Publish Branch sends your work to GitHub so it can be reviewed.

**Official Documentation**

# 7 — Synchronize Changes

Synchronize Changes updates your local copy of the MSB Documentation Project with GitHub and uploads any approved local commits.

**Official Documentation**

https://code.visualstudio.com/docs/sourcecontrol/overview

# 8 — Pull Requests

A Pull Request asks the project reviewer to examine your proposed documentation changes before they become part of the official project.

**Official Documentation**

https://code.visualstudio.com/docs/sourcecontrol/github

GitHub Pull Requests Documentation:

https://docs.github.com/pull-requests
