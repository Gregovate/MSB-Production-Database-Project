# MSB Documentation Images

This folder contains screenshots and graphics used throughout the MSB Documentation Project.

## Guidelines

- Store each image only once.
- Use descriptive filenames.
- Use lowercase letters.
- Separate words with hyphens.
- Prefer PNG format for screenshots.
- Replace outdated images rather than creating duplicates when practical.
