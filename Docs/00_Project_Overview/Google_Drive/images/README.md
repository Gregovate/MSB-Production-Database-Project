# Google Drive Documentation Images

Store repository documentation images here when they belong specifically to the Google Drive / Display Folder documentation subsystem.

Examples include:

- screenshots used by Google Drive operator SOPs;
- diagrams explaining Display Folder organization;
- annotated examples used by Google Drive documentation; and
- images shared by both operator and engineering documents in this subsystem.

Do not use a repository-wide `Docs/images/` folder for new Google Drive documentation images merely for convenience.

If an image clearly belongs to another subsystem, store it with that subsystem instead.

## Important Distinction

This repository folder is for **documentation assets in Git**.

It is not the same as operational Google Drive folders such as:

```text
Procedures\Setup\images
Procedures\Takedown\images
```

Those folders contain field-procedure assets inside the Google Shared Drive and are governed by the Display Folder procedures.
