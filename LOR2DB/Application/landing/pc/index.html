Install / Repair PC Updater

  1. Download the installer package and extract all files to a folder on this PC.
  2. Double-click Setup MSB PC Preview Updater.vbs in that folder.
  3. Wait for the installation confirmation. Use the new MSB PC Preview Updater Desktop shortcut, or return here and click Open PC Preview Updater.

Install while signed into the Windows account you use for Light-O-Rama. No administrator sign-in is needed. Light-O-Rama must use C:\LOR as its data folder. Installation does not require the shared drive.

Comparison-only test: this release checks your previews but cannot apply changes. Send the result or any error to the MSB administrator.
