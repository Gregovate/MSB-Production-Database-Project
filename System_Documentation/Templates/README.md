# Documentation Templates

This folder contains controlled templates used to create consistent MSB documentation.

Templates are document-type specific. Do not force every procedure, field instruction, engineering document, or administrative document into one layout.

## Current Template Families

| Document Type | Template / Standard | Intended Use |
|---|---|---|
| Repository Operational SOP | Follow the [Operational SOP Standard](../Standards/Operational_SOP_Standard.md) | Tasks performed within MSB systems, applications, database workflows, or repository-owned operations |
| Stage Setup Instruction | [Stage Setup Instruction Template](Stage_Setup_Instruction_Template.md) | Field-facing instructions used by volunteers to physically set up a Stage, Scene, or related group in the park |

Additional templates should be added only when a real document class needs a materially different structure.

## Template Rules

- Templates follow the applicable reusable standards and project-specific rules.
- A template is not the governing standard; it is the controlled starting structure for that document type.
- Keep formatting durable and structural. Avoid fragile manual formatting that is difficult to reproduce consistently.
- Reusable branding assets such as the MSB logo should come from an approved reusable public location rather than being copied into every document set.
- Document-specific images should follow the owning document class's asset-location rule.
- When a template changes materially, review the contributor procedure that explains how to use it.

## Stage Setup Instructions

Stage Setup Instructions are governed by the [Stage Setup Documentation Standard](../Project_Rules/Stage_Setup_Documentation_Standard.md).

They are intentionally different from repository Operational SOPs. Their primary audience is the field volunteer, and their published presentation should remain simple even when the underlying identity, database, Google Drive, QR, and intranet systems are more complex.
