MSB PC Preview Updater 1.1.2 — October 31, 2026

Requires Light-O-Rama 6.6.12 Pro using C:\LOR as its data folder.

1. Close Light-O-Rama.
2. Visit https://my.sheboyganlights.org/lor2db/pc/
3. Click Install / Update PC Updater. Save the ZIP in Downloads.
4. In Downloads, right-click the ZIP and choose Extract All. Keep the
   suggested folder inside Downloads, then click Extract.
5. Open the extracted folder and double-click Setup MSB PC Preview Updater.vbs.
6. Wait for the installation confirmation.
7. On https://my.sheboyganlights.org/lor2db/pc/ click Open PC Preview Updater.
   Allow the browser to open the app if prompted, then return to the updater.
8. Select each preview to review its pending changes. Show full details is
   available if needed. Leave Match master Revision unchecked.
9. Confirm Light-O-Rama is closed and approve the listed changes, then click
   Update PC Previews. Wait for the success message before reopening LOR.

Linked backgrounds stay external files; no images are embedded. Google Drive
must be running and the shared files synced before updating. A missing or
changed image blocks the update and identifies the file to check.
Personal/imported/store previews are preserved. A backup is made before writes.
Use the same webpage for later updates, or the Desktop shortcut.
